## ✨ Features & Modules

1. **🏛️ Grand University Masthead & Navigation**
   - High-resolution vector emblem, stately serif typography, and accreditation badges (**NAAC 'A++' 3.84 CGPA**, **NIRF #24**, **NBA Tier-1**).
   - Sticky navbar starting directly with *Home*, plus mobile navigation drawer.

2. **🏠 Home Page**
   - High-impact hero section, quick campus counters (85+ Acres, 12,500+ Scholars, 480+ Professors).
   - **From the Principal's Desk** address card with custom photographic portrait.
   - Recruiter marquee (Google, Microsoft, Amazon, TCS, Infosys, etc.).

3. **📜 About University**
   - 42-year milestone timeline (since 1984 under the Alshifa Educational Trust), institutional pillars, and leadership message.

4. **🏢 8 Academic Departments**
   - CSE, IT, ECE, MECH, CIVIL, AI&DS, MBA, and MCA with HOD details, lab highlights, and intake numbers.

5. **📚 Course Directory**
   - Searchable UG & PG degree catalog with real-time keyword filtering and interactive syllabus preview modal.

6. **📝 Online Admissions 2026-27**
   - Step-by-step admission roadmap, cutoff deadlines, scholarship matrix, and multi-step application modal with instant receipt generation.

7. **👨‍🏫 Faculty Directory**
   - Searchable directory of 16+ verified professors with Ph.D. credentials and research metrics.

8. **🏟️ Campus Facilities**
   - Central Digital Library (180k+ volumes), High-Performance Supercomputing Clusters, Olympic Sports, and Smart Auditoriums.

9. **💼 Training & Placements**
   - 96.4% placement rate, ₹48.5 LPA peak package, and a 4-year career incubation roadmap.

10. **📰 Events & Newsroom**
    - Categorized university news, official administrative circulars, and event RSVP registration.

11. **🖼️ Campus Life Gallery**
    - 5 categories of campus life with interactive full-screen Lightbox modal.

12. **🎓 Interactive Student Portal Dashboard**
    - Scholar demo (`AU/2023/CS-108`) with live timetable, subject-wise attendance rings, internal grades, and digital fee receipts.

13. **📞 Contact & Campus Navigation**
    - Feedback form, directory of administrative hotlines, and embedded Google Map.

## 🛠️ Technology Stack

- **Frontend**: React 19 (`react`, `react-dom`)
- **Build Tool**: Vite 8
- **Styling**: Modern Responsive Vanilla CSS3 (Custom properties, CSS Grid, Flexbox, Media Queries)
- **Icons**: Lucide React (`lucide-react`)
- **Fonts**: Google Fonts (`Cinzel` serif & `Inter` sans-serif)
- **Zero Heavy UI Libraries**: Built from scratch without Bootstrap or Tailwind for maximum performance.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18.0 or higher)
- [Git](https://git-scm.com/)

### Installation & Local Run

```bash
# 1. Clone the repository
git clone https://github.com/YOUR_USERNAME/alshifa-university-website.git

# 2. Navigate to the project directory
cd alshifa-university-website

# 3. Install dependencies
npm install

# 4. Run the development server
npm run dev
```

Open [http://localhost:5173/](http://localhost:5173/) in your browser.

---

## 📦 Production Build

```bash
npm run build
```
Build output will be generated inside the `dist/` directory.
